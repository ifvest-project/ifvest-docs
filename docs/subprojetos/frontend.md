# Eixo 1: Interface e Modernização (Frontend)

Este eixo foca na experiência do usuário, no design da interface e na modernização da arquitetura frontend da plataforma IFVest. Os projetos visam a migração para tecnologias mais recentes e a implementação de uma nova identidade visual, garantindo uma experiência de usuário aprimorada e uma base tecnológica robusta para o futuro.

## Projetos Principais

### Refatoração para React e Redesign da Interface

*   **Líderes:** Isabella e Maria Luiza
*   **Objetivo:** Atualizar a identidade visual do IFVest, refatorar o frontend para React e aprimorar a experiência do usuário, com foco em componentização e responsividade.
*   **Tecnologias Envolvidas:** React, Figma (para design e prototipagem), HTML, CSS, JavaScript.
*   **Destaques:**
    *   Desenvolvimento de uma nova identidade visual completa no Figma, abrangendo cores, tipografias e vetores de autoria própria para ícones e estilização.
    *   Criação de componentes reutilizáveis para padronização da interface e facilidade de manutenção.
    *   Integração com Google Authentication para simplificar o processo de login e cadastro.
    *   Redesenho de módulos críticos como autenticação, perfil do usuário e revisão de conteúdo, com foco em usabilidade e acessibilidade.
    *   Implementação de um novo fluxo para o módulo de Revisão de Conteúdo, dividindo os materiais por áreas (Matemática, Ciências Humanas, etc.) e exibindo métricas de desempenho para o estudante.
    *   Adição de funcionalidades como recuperação de senha em três etapas e reestruturação da página de perfil do usuário com opções de alteração de foto e exclusão de conta.

### Continuidade e Aprimoramento do Módulo Quiz

*   **Líder:** Helena
*   **Objetivo:** Dar continuidade ao IFQuiz na nova plataforma, revendo os requisitos e as telas do módulo.
*   **Tecnologias Envolvidas:** Figma (para as telas), React, FastAPI e Swagger (para a documentação da API).
*   **Destaques:**
    *   Levantamento dos requisitos funcionais e não-funcionais do IFQuiz.
    *   Desenvolvimento das telas do módulo no Figma, alinhadas com a equipe do redesign da interface.
    *   Definição dos filtros de questões do quiz com as equipes do banco de questões.
    *   Participação na escolha do Python com FastAPI como padrão do backend e início da documentação da API no Swagger.
